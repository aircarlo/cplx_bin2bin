# cplx_bin2bin
This repository contains the PyTorch implementation of complex-bin2bin, as described in _"[Complex-bin2bin: A Latency-Flexible Generative Neural Model for Audio Packet Loss Concealment](https://doi.org/10.1109/TASLP.2024.3515794)"_ IEEE Transactions on Audio, Speech and Language Processing, Dec, 2024.

Additionally, you can enter the [demo page](https://aircarlo.github.io/cplx_bin2bin/) which features some sample audio files.
